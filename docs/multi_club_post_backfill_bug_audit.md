# Multi-Club Post-Backfill Bug Audit

Run date: 2026-05-27

Branch: `onboarding/multi-club-positive-responses`

Scope: six onboarded pilot clubs plus FVCC regression. This audit used existing local processed/deploy-safe outputs and ignored local match-centre/review-pack inputs only. No data was fetched and no match-centre/backfill pipeline was rerun.

## Root Causes

- Hall of Fame Win % was generated from `result_text` with a hard-coded `fiji victorian` winner check. Non-FVCC clubs therefore treated every attributable result as a loss.
- Scorecard milestone rows were identity-mapped without passing the active `club_id`, so Southside's club-local `manual_player_merges.csv` did not collapse raw scorecard profiles into the canonical aggregate player ids used by HOF Detailed Records.
- Theme CSS kept FVCC purple as hard-coded sidebar/tab/accent styling even when club configs supplied active club colours.
