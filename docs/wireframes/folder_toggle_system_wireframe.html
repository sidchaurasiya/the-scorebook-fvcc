Folder Toggle System

Standalone wireframe · no app logic

Component Idea

Folder tabs attach directly to the table or visual they control. The active tab reads as the front sheet of the module; inactive tabs sit slightly recessed.

Use folder tabs for module-level views: Season by Round grade/team, Milestone view, and Player Profile Career Breakdown dimension. Keep pill controls for discipline or metric switches: Batting / Bowling / Fielding and similar smaller in-card controls.

Mobile behaviour

Compact tab wrapping

A narrow preview showing how folder tabs avoid the oversized capsule problem while staying attached to the visual.

Implementation idea: one shared folder-tab component with `selected_key`, `options`, compact labels, and a target content container. Streamlit state can still be session-state based; this wireframe is visual only.
Folder tabs should not update URLs or behave like links in production. Use two-column mobile wrapping for longer sets; use one row when there are only two or three short labels. Keep table/card content immediately below the folder edge so the tabs feel physically connected.
